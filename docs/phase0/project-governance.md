# CBT Project Governance Structure

## Project Board Constitution

### Executive Sponsorship
**Position:** Vice-Chancellor or Deputy Vice-Chancellor (Academic)
**Responsibilities:**
- Executive-level decision making and resource allocation
- University-wide policy alignment
- Final approval for major milestones and budget decisions
- Risk mitigation at institutional level

### Steering Committee
**Composition:**
- GST Coordinator (Chair)
- Dean of Student Affairs
- ICT Director
- Senate Representative
- Project Manager (Secretary)
- Security Engineer (Advisor)

**Mandate:**
- Approve major project milestones and deliverables
- Ensure compliance with university academic integrity policies
- Review and approve security and data privacy frameworks
- Facilitate inter-departmental coordination
- Monitor project performance against KPIs

**Meeting Cadence:**
- Bi-weekly during development phases
- Weekly during critical periods (exam periods, major deployments)
- Ad-hoc emergency sessions for critical issues

### Decision Making Authority Matrix

| Decision Area | Authority | Consultation Required | Information Required |
|---------------|-----------|----------------------|---------------------|
| Budget > $10,000 | Executive Sponsor | Steering Committee | Business case, ROI analysis |
| Technical Architecture | ICT Director | Security Engineer | Technical specifications, security assessment |
| Academic Policy Changes | Senate Rep | GST Coordinator | Policy impact analysis |
| Security Incidents | Security Engineer | ICT Director | Incident report, mitigation plan |
| Timeline Changes | Project Manager | Steering Committee | Revised project plan, impact analysis |

### Escalation Path
1. **Team Level:** Project Manager → Steering Committee
2. **Department Level:** Department Heads → Executive Sponsor
3. **Crisis Level:** Any team member → Executive Sponsor (with immediate notification to all stakeholders)

### Communication Protocols
- **Critical Production Issues:** 15-minute response SLA during exam periods
- **Security Incidents:** Immediate escalation to Security Engineer and ICT Director
- **Academic Policy Concerns:** 24-hour response to GST Coordinator
- **Technical Issues:** 1-hour response during business hours, 4-hour after hours

### Success Metrics
- Project completion within 6-month timeline
- Zero security breaches during exam periods
- Student satisfaction score > 80%
- Lecturer adoption rate > 90%
- System availability > 99.5% during exams
